## Main finding

The plan's design was **replaced**, not built as written. Main runs a **4-agent loop** (Writer → Structurer → SEO → Critic, max 3 rounds; see [orchestrator.py#L1-L22](https://github.com/DevelopersCoffee/BrewPress/blob/bd843ffb44d622e563e2b4bf4255fb7c9cec1ad1/src/brewpress/orchestrator.py#L1-L22)). DraftAgent was deleted ([`bf4d950`](https://github.com/DevelopersCoffee/BrewPress/commit/bf4d950)). `_extract_json` was superseded by `response_schema` rather than deduplicated. BoostEval and BlogBoostAgent are not in the loop. **New P1 risk:** the default model id, `gemini-2.0-flash`, is retired (RISK-1).
