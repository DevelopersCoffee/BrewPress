## Main finding

The plan's design was **replaced**, not built as written. Main runs a **4-agent loop** (Writer → Structurer → SEO → Critic, max 3 rounds), as described in [orchestrator.py#L1-L22](https://github.com/DevelopersCoffee/BrewPress/blob/bd843ffb44d622e563e2b4bf4255fb7c9cec1ad1/src/brewpress/orchestrator.py#L1-L22). DraftAgent was deleted ([`bf4d950`](https://github.com/DevelopersCoffee/BrewPress/commit/bf4d950)). `_extract_json` was **removed** in favour of `response_schema` structured output ([`87077da`](https://github.com/DevelopersCoffee/BrewPress/commit/87077da), [`6d4885b`](https://github.com/DevelopersCoffee/BrewPress/commit/6d4885b)) rather than deduplicated into `_llm_utils.py`. BoostEval and BlogBoostAgent are **not in the loop**. Several plan items are either superseded or still open. They are listed below.
