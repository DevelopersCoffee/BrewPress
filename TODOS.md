## P2 — Medium Priority

### WP-1: 'Already wrote about this?' duplicate detection

**What:** Before generating, query WP REST API for posts with matching slug or
similar title. If near-duplicate found, warn: "Similar post: '{title}' (published
{date}). Draft as update instead?"

**Why:** Prevents duplicate posts as blog grows. Essential at 50+ posts.
**Pros:** Prevents content duplication; surfaces update opportunities.
**Cons:** Adds ~200ms WP search call per draft run.
**Effort:** S (human: ~2 hr / CC: ~20 min)
**Priority:** P2
**Depends on:** Stack 6 (WordPress client complete)

### GH-1: PR URL input (--pr-url flag)

**What:** `brewpress draft --pr-url https://github.com/DevelopersCoffee/BrewPress/pull/42`
fetches diff from GitHub API directly.

**Why:** Better UX when writing about merged PRs. Removes `git diff > tmp.diff` step.
**Pros:** Works without local clone. Unauthenticated for public repos.
**Cons:** Requires `GITHUB_TOKEN` for private repos.
**Effort:** S (human: ~1 day / CC: ~30 min)
**Priority:** P2
**Depends on:** Stack 4 (DiffParser accepts diff string, not just file path)
**Note:** Phase 2 per original PRD.

## P3 — Low Priority / Vision

### WATCH-1: CLI watch mode

**What:** `brewpress watch` monitors git log for new commits; auto-runs
`brewpress draft` on each. You approve, the blog publishes.

**Why:** This is the 10x vision — publishing becomes a side effect of building.
**Pros:** Zero-friction corpus building. Direct path to knowledge-base moat.
**Cons:** Complex (fswatch/polling). Auto-generation without intent check = garbage drafts.
**Effort:** L (human: ~1 week / CC: ~2-3 hr)
**Priority:** P3
**Depends on:** Stack 4 + Stack 6 stable and proven on real posts.

**Why:** Contradiction will confuse future contributors about whether topic-only posts are first-class or second-class.
**Pros:** ~10 minutes of doc editing removes ambiguity permanently.
**Cons:** None significant.
**Effort:** XS (CC: ~5 min)
**Priority:** P3
**Depends on:** Stack 1 complete (so the actual CLI interface is settled)
